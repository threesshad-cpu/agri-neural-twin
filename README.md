# Agri-Neural Twin 🌱🤖

**The District Intelligence & Agricultural Risk Engine for Tamil Nadu.**

Agri-Neural Twin is a next-generation "Digital Twin" dashboard designed to empower farmers and policymakers with real-time agricultural intelligence. By combining historical data with neural network simulations, it predicts market gluts, optimizes crop selection, and mitigates climate risks.

![Agri-Neural Twin Dashboard](https://via.placeholder.com/800x400?text=Agri-Neural+Twin+Dashboard+Preview)

## 🚀 Features

*   **District Intelligence Dashboard**: Real-time metrics for 38+ districts (Nitrogen, Phosphorus, Potassium, Water Levels).
*   **Geospatial Simulation**: Interactive map allowing block-level analysis for precise interventions.
*   **AI-Powered Risk Engine**: "What-If" analysis to predict Market Saturation and Profitability for **1,000 future seasons**.
*   **Neural Forecasting**: Detects "Market Gluts" (e.g., Tomato oversupply) and "High Profit" opportunities (e.g., Turmeric).
*   **Farmer-First Design**: Mobile-responsive, high-contrast, and intuitive interface optimized for on-the-go usage.

## 🛠️ Technology Stack

*   **Frontend**: React 19 + Vite (Lightning fast)
*   **Styling**: Modern CSS Grid + CSS Variables (No bloat)
*   **Design System**: Custom "Agriculture-Tech" Palette (Emerald Greens, Earthy Browns, Alert Reds)
*   **AI Pair Programmer**: **Gemini 3 Pro** (Reasoning, Architecture, Logic)
*   **Deployment**: Ready for Vercel/Netlify

## 🌍 Impact on Tamil Nadu Agriculture

1.  **Risk Mitigation**: Prevents massive losses by predicting market gluts before seeds are even sown.
2.  **Resource Optimization**: Maps water usage to specific crop needs (e.g., Sugarcane vs. Groundnut), crucial for drought-prone zones.
3.  **Economic Growth**: Shifts farmers from subsistence models to data-driven, high-yield "Smart Farming".

## 📱 Hackathon Ready & Mobile Optimized

Designed for the field:
*   **Responsive Grid**: Transitions from complex 3-column desktop view to clean single-column mobile view.
*   **Touch Targets**: Enhanced button sizes and input fields for easy interaction on low-end smartphones.
*   **Performance**: Lightweight CSS-only animations ensuring 60fps performance without heavy libraries.

## 🏁 Getting Started

1.  **Install Dependencies**:
    ```bash
    npm install
    ```
2.  **Launch Neural Twin**:
    ```bash
    npm run dev
    ```
3.  **Simulate**: Select "Tomato" with >50 acres to see the AI Risk Engine in action.
